
# VERSUM KitchenWare ERP

## Project Overview
VERSUM KitchenWare ERP is a web-based Enterprise Resource Planning system designed to manage kitchenware business operations through a centralized platform.

## Key Features
- Dashboard and business overview
- Product and category management
- Raw material inventory management
- Stock movement tracking
- Production management
- Dealer management
- Purchase management
- Sales and invoice management
- Business reports

## Technology Stack
- ASP.NET Core MVC
- C# and .NET 10
- Entity Framework Core 10
- Microsoft SQL Server
- HTML, CSS, JavaScript and Bootstrap

## CI Pipeline
The project uses GitHub Actions to automatically restore dependencies, build the application and run automated tests when available.

## Team Collaboration
This project follows a GitHub-based team collaboration workflow using feature branches, commits and pull requests.

## Project Status
Under active development and improvement.
